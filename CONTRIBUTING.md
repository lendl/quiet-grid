# Contributing to Quiet Grid

Thanks for wanting to help. Quiet Grid is a small project with one maintainer, so a little coordination up front saves everyone time.

## Ways to help

- **Report a bug.** Use **Report bug** on the Support screen (it fills in your app version), **Report a problem** in the ⋮ menu of a result screen (it also fills in the exact puzzle), or open a [bug report](https://github.com/lendl/quiet-grid/issues/new?template=bug_report.yml).
- **Share an idea.** Small improvements can go in a [feature request](https://github.com/lendl/quiet-grid/issues/new?template=feature_request.yml). New games and bigger changes belong in [Discussions > Ideas](https://github.com/lendl/quiet-grid/discussions/categories/ideas).
- **Suggest theme words.** The theme words sheet in Word Search and Theme Clear can open a prefilled issue.
- **Improve a translation.** See [Translations](#translations) below.
- **Send code.** See below.

## Sending code

- For anything beyond a small fix, open an issue or discussion first and wait for a reply. This matters most for **new games**: they're a big commitment to review and maintain, and it would be a shame to build one that doesn't fit.
- Quiet Grid stays **offline, ad-free and account-free**. Changes that add network access, analytics, ads, sign-in or new permissions won't be merged.
- Keep each pull request to one change, and include before and after screenshots for anything visible.
- Build setup and puzzle generation are in [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md), and how to run the tests is in [`docs/testing.md`](docs/testing.md).

## Translations

Quiet Grid is available in English, Dutch, German, French, Spanish, Portuguese, Polish and Italian.

- Fixes to existing translations are always welcome.
- Recent features are often English-only on purpose while they're still changing. They get translated once they're ready.
- To add a new language, open an issue first.
