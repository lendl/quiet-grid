`CLAUDE.md` at the repo root for the always-on, short version of these conventions; the docs here
are the deeper reusable-context/workflow packets for adding a new game.

`specs/` and `plans/` are historical design records from the original (RN-era) doc system — kept for
context on *why* this doc split exists, not rewritten for Kotlin. Don't treat their file paths or
commands as current; use the docs below instead.
