# Security policy

## Supported versions

Only the latest release of Quiet Grid gets fixes. Please update to the newest version from [F-Droid](https://f-droid.org/en/packages/com.quietgrid.app/), [Google Play](https://play.google.com/store/apps/details?id=com.quietgrid.app) or [GitHub Releases](https://github.com/lendl/quiet-grid/releases/latest) before reporting.

## Scope

Quiet Grid has no internet permission, no accounts and no analytics, and all data stays on the device (see [PRIVACY.md](PRIVACY.md)). Issues that are still worth reporting privately include:

- a way for another app or file to read or change Quiet Grid's saved data
- the app requesting a permission or making a network connection it shouldn't
- a problem in the release build, signing or a bundled dependency

## Reporting a vulnerability

Please **don't open a public issue**. Instead:

- use [Report a vulnerability](https://github.com/lendl/quiet-grid/security/advisories/new) on GitHub, or
- email **quiet-grid@outlook.com** with "Security" in the subject.

Include what you found, how to reproduce it, and the app version. You'll get a reply within a week. Once a fix is released, you'll be credited in the release notes unless you'd rather not be.
